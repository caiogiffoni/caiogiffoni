## 🚀 Featured projects

### 🗂️ [jidoka](https://github.com/caiogiffoni/jidoka) — *kanban driven by an LLM agent*
A Trello-style board you can drive by hand or through a LangGraph agent that proposes changes as diffs and pauses for human-in-the-loop approval before anything touches the board. Eval suite runs against real LLMs in CI.
`Python · FastAPI · LangGraph · Next.js · PostgreSQL`

### 🚛 [ELD Trip Planner](https://github.com/caiogiffoni/truck-trip-planner-back) — *HOS-compliant trip scheduling*
REST API calculating hours-of-service-compliant schedules for truck drivers.
`Python · Django · DRF · Pydantic · Docker`

### 🍅 [Pomodoro Timer Desktop](https://github.com/caiogiffoni/pomodoro-timer-desktop) — *focus tracker for Linux*
Full-featured desktop productivity app with stats dashboard and streak tracking.
`Python · PyQt6 · SQLite`
